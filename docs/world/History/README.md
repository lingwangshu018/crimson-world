# 历史与纪年

这里记录绯界的时代划分、编年史、战争、迁徙、灾难、发明与重大社会变化。

建议每个历史事件至少包含：

- 时间与所属纪元
- 地点
- 参与国家、组织与人物
- 起因、经过与结果
- 对当代世界的影响
- 相关遗迹、节日或馆藏

历史不只解释过去，也应说明今天为什么会变成这样。
