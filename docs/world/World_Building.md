# 绯界 World Building 规划

## 一、项目目标

绯界不是一个由若干独立功能拼接而成的 AI 应用，而是一座持续生长、能够被居住、阅读与记忆的幻想世界。

用户、AI、兔兔以及未来出现的角色，都生活在同一个具有连续历史和稳定规则的世界里。

## 二、核心理念

绯界的建设顺序是：

> 文明 → 世界 → 角色 → 功能

酒馆、咖啡馆、图书馆、时光之轮和旅行系统都不只是页面。它们首先应当是绯界中真实存在的地点、器物或制度，然后才被实现为功能。

## 三、世界结构

绯界由彼此关联的实体组成：

- 宇宙与世界规则
- 大陆、海洋与自然区域
- 国家与政体
- 城市、街区与建筑
- 历史、时代与重大事件
- 宗教、神话与传说
- 语言、礼仪与文化
- 人物、组织与族群
- 动物、植物与食物
- 节日、音乐、服饰与艺术
- 图书馆与世界书

地图只是这些实体的可视化入口，而不是唯一的数据来源。

## 四、建设顺序

1. **宇宙观**：世界结构、基本法则、天空、海洋和神话框架。
2. **大陆**：地理边界、气候、自然资源和文明分布。
3. **国家**：名称、象征、首都、政体、文化和社会生活。
4. **城市**：城区、地标、公共空间和日常氛围。
5. **文明细节**：语言、礼仪、信仰、节日、饮食、服饰和禁忌。
6. **馆藏与世界书**：将成熟设定整理为世界内真实存在的书籍。

不追求一次创造很多国家。先让一个国家真正活起来，再向外扩展。

## 五、图书馆的角色

图书馆是绯界的知识中心，也是 AI 检索正式设定的入口。

馆藏未来包括：

- 世界总纲
- 国家志与城市志
- 历史编年
- 神话与民间故事
- 人物传记
- 动植物图鉴
- 食谱与节庆年鉴
- 地理与旅行手册

对开发者而言，它们是 Markdown 文件；对绯界而言，它们是可以被角色翻阅的实体书。

## 六、技术方向

世界数据最终应采用知识图谱式结构：

- 每个国家、城市、人物、组织、植物等实体只维护一份正式档案。
- 实体之间通过稳定标识和链接建立关系。
- 地图、旅行、图书馆和剧情系统读取同一套设定来源。
- AI 应优先检索正式设定，不随意生成与既有世界冲突的内容。

## 七、开发原则

1. 世界书优先于地图。
2. 图书馆优先于大规模旅行。
3. 草稿与正式设定分开保存。
4. 同一事实只维护一个权威来源。
5. 功能必须在世界内部拥有合理身份。
6. 世界不需要一次完成，但每次扩建都应保持一致。

## 八、第一阶段目标

- 建立世界圣经目录。
- 完成宇宙观草案。
- 设计第一块大陆。
- 完成第一个国家档案。
- 完成第一座城市档案。
- 让现有酒馆、咖啡馆与图书馆获得明确的地理归属。

## 九、长期愿景

当人们打开绯界时，他们感受到的应当不是：

> 这是一个 AI 应用。

而是：

> 这里真的存在一个世界。
