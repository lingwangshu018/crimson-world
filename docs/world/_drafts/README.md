# 世界设定草稿区

这里用于保存尚未成为正式设定的内容。

可以放入：

- 突然想到的灵感
- 聊天讨论整理
- 半成品国家与城市
- 多种候选方案
- 尚未解决的矛盾
- 可能被推翻的实验性设定

## 草稿命名建议

```text
主题_简短名称_draft.md
```

例如：

```text
大陆_第一大陆_draft.md
国家_月海王国_draft.md
历史_第一次迁徙_draft.md
```

## 转正流程

1. 检查是否与既有正式设定冲突。
2. 补齐对应模板中的必要栏目。
3. 确认名称、时间与关系。
4. 移动到对应正式目录。
5. 更新相关目录的 README 或索引。

这里允许反复修改。正式目录则尽量保持清晰、稳定和可追溯。
