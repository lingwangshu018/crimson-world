# 绯界世界圣经（Crimson World Bible）

这里收藏绯界的世界观、历史、国家、城市、文化与馆藏设定。

它既是开发资料库，也是绯界图书馆的原始馆藏。

## 推荐阅读顺序

1. [世界设计总纲](./World_Building.md)
2. `Universe/`：宇宙观与世界结构
3. `Continents/`：大陆、海洋与区域
4. `Nations/`：国家档案
5. `Cities/`：城市档案
6. `History/`：历史、纪年与重大事件
7. `Cultures/`：语言、礼仪、服饰、艺术与习俗
8. `Library/`：会在绯界图书馆中出现的书籍与世界书

## 收藏夹说明

| 位置 | 放什么 |
| --- | --- |
| `_drafts/` | 灵感、讨论稿、半成品与待确认设定 |
| `templates/` | 国家、城市等设定模板 |
| `Universe/` | 宇宙、天体、世界规则与神话框架 |
| `Continents/` | 大陆、海域、山脉与自然区域 |
| `Nations/` | 国家、政体、象征与社会生活 |
| `Cities/` | 城市、城区、地标与日常氛围 |
| `History/` | 纪年、时代、战争、迁徙与重大事件 |
| `Cultures/` | 文化、语言、礼仪、节庆、饮食与禁忌 |
| `Library/` | 馆藏目录、书籍正文与可供 AI 检索的世界知识 |

## 使用原则

- 新想法先写进 `_drafts/`，确认后再移动到正式目录。
- 新建国家或城市时，优先复制 `templates/` 中的模板。
- 同一个实体只维护一份正式档案，其他文件通过链接引用。
- 世界设定与代码分开保存，但功能实现应尊重这里的正式设定。
- 每开发一个功能，都先问：**它在绯界里是什么？**
