# 文化档案

文化条目应尽量解释：

- 人们具体怎么做
- 为什么形成这种习惯
- 不同地区或阶层有何差异
- 外来者容易产生什么误解
- 它会如何出现在日常生活和剧情中

避免只列标签，要让文化能够被角色真正生活出来。
