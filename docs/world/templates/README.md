# 世界设定模板收藏夹

这里存放绯界世界设定的统一模板，避免每次从零开始，也避免不同文档结构越来越乱。

## 当前模板

- `Country_Template.md`：国家档案模板
- `City_Template.md`：城市档案模板

- 生物模板

## 使用方法

1. 复制对应模板。
2. 重命名为正式实体名称。
3. 先放进 `_drafts/` 填写和讨论。
4. 设定确认后移动到正式目录。

请不要直接复制已有国家或城市作为新档案，因为旧档案中可能带有特殊栏目或遗留设定。
