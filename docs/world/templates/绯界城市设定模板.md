# 城市设定模板
## ——适用于绯界世界观、旅行系统与城市资料库

> 本模板参考曦庭城的设定结构，用于创建新的城市。
>
> 建议填写顺序：
>
> **城市定位 → 地理 → 城市结构 → 街区 → 建筑 → 居民 → 制度 → 文化 → 旅行内容**
>
> 不需要一次全部填满。可以先完成核心设定，再逐步补充人物、生物、店铺、食物、礼物、信件与事件。

# 十六、建议文件拆分结构

城市内容较多时，建议拆分为：

```text
cities/
└── city-id/
    ├── city.md       # 城市本体：地理、街区、建筑、居民、制度
    ├── map.md        # 地图节点、路线与旅行读取结构
    ├── shops.md      # 店铺与商业地点
    ├── foods.md      # 美食与饮品
    ├── gifts.md      # 礼物与赠礼触发故事
    ├── letters.md    # 旅行信件模板
    ├── creatures.md  # 动物、植物、昆虫、菌类与灵性生物
    ├── npcs.md       # 代表人物与普通居民
    └── events.md     # 城市随机事件与剧情节点
```

### `city.md`

回答：

> 这座城市是什么？

### `map.md`

回答：

> 旅人可以去哪里？地点之间如何连接？
