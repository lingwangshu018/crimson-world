# 绯界图书馆馆藏

这里保存会在绯界图书馆中真实出现的书籍、档案、手稿与世界书。

对开发者而言，它们是 Markdown 文档；对绯界而言，它们是可以被阅读、引用和传承的馆藏。

## 可以收藏

- 世界总纲与百科
- 国家志、城市志与地方志
- 历史编年与人物传记
- 神话、民间故事与诗歌
- 动植物图鉴
- 食谱、节庆年鉴与旅行手册
- 角色留下的日记、书信与研究笔记

## 馆藏原则

- 区分作者观点与世界客观事实。
- 可以允许书籍彼此矛盾，但要标明作者、年代与立场。
- 正式设定的权威来源仍由世界圣经索引确定。
- AI 引用馆藏时，应保留来源与语境，不把传说自动当成事实。

这里最终会成为绯界图书馆页面读取的主要内容来源。
