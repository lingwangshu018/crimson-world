# 绯界操作指南（小白版）

这份指南写给第一次使用绯界、不了解 Git、Cloudflare 或 MCP 的用户。

你不需要会写代码。日常使用只需要：

1. 打开绯界网页。
2. 在房间里创建记录。
3. 点击“发送给 AI”。
4. 把自动复制的任务单发给已经接入绯界 MCP 的 AI。
5. 回到绯界收取回复。

---

## 一、先打开绯界

正式入口：

```text
https://crimson-world.lingwangshu018.workers.dev
```

建议使用最新版 Chrome、Edge、Safari 或其他现代浏览器。

第一次打开时，绯界的数据会先保存在当前浏览器中。换浏览器、换设备、清理浏览器数据后，本地记录不会自动跟过去，所以重要内容请定期备份。

| 房间 | 可以做什么 |

## 三、第一次使用必须做的设置

### 第一步：打开绯界控制中心

点击页面上的云端悬浮球，再进入“存档中心”或“绯界控制中心”。

第一次使用时，系统会为当前浏览器准备三把钥匙。

| 钥匙 | 用途 | 能不能发给别人 |
| --- | --- | --- |
| 主人钥匙 | 同步、覆盖和恢复完整云端档案 | 不可以 |
| 读取钥匙 | 让 AI 读取已经同步的记录 | 只在任务单中使用 |
| 回复钥匙 | 让 AI 把回复写回已有记录 | 只在任务单中使用 |

请不要把主人钥匙截图公开，也不要写进公开仓库、角色卡或世界书。

### 第二步：执行一次“全部同步”

在控制中心点击：

```text
全部同步
```

这一步会把当前记录和三把钥匙的校验信息同步到 Cloudflare。

只有完成同步后，外部 AI 才能读取到记录。

### 第三步：保存一份本地备份

点击：

```text
导出全部
```

浏览器会下载一个 JSON 文件。请把它放到你找得到的位置，例如：

```text
文档/绯界备份/
```

这个备份不包含三把钥匙，因此钥匙仍需单独妥善保存。

## 四、配置 MCP

绯界 MCP 地址：

```text
https://crimson-world.lingwangshu018.workers.dev/api/mcp
```

在支持“远程 HTTP MCP”的 AI 客户端中，新建一个 MCP 服务，并填写上面的地址。

常见填写方式：

| 设置项 | 填写内容 |
| --- | --- |
| 名称 | 绯界 / Crimson World |
| 类型 | Remote HTTP、HTTP MCP 或 Streamable HTTP |
| URL | `https://crimson-world.lingwangshu018.workers.dev/api/mcp` |
| 认证 | 通常不需要在这里填写；读取钥匙和回复钥匙会随任务单传入 |

保存后，客户端应能看到三个工具：

```text
read_crimson_record
search_crimson_records
write_crimson_reply
```

不同客户端可能把工具名翻译成中文，例如“读取绯界记录”“搜索绯界记录”“写回绯界回复”。这是正常的。

### 怎么确认 MCP 接好了？

可以在 AI 聊天中问：

```text
请告诉我当前是否能看到绯界 MCP 工具。
```

能够看到读取、搜索、写回三个工具，就说明连接基本成功。

## 五、创建角色卡和世界书

这一步不是强制的，但推荐先设置。这样 AI 写出来的内容会更符合角色人设和世界观。

### 创建角色卡

1. 打开“皇家图书馆”。
2. 点击“进入编纂室”。
3. 选择“角色”。
4. 点击“新建角色”。
5. 填写角色名、昵称和人物设定。
6. 确认“启用角色”已经勾选。
7. 点击保存。

人物设定可以写：

```text
身份、性格、经历、说话方式、与用户的关系、称呼习惯、不能做的事情。
```

### 创建世界书

1. 在编纂室切换到“世界书”。
2. 点击“新建世界书”。
3. 填写标题和条目内容。
4. 选择“公共世界书”或“角色世界书”。
5. 角色世界书需要勾选适用角色。
6. 可填写关键词；留空时会始终生效。
7. 确认条目已启用，然后保存。

### 公共世界书和角色世界书有什么区别？

- 公共世界书：所有启用角色都可以使用。
- 角色世界书：只在指定角色参与时使用。

创建记录时，绯界会把当时匹配到的角色卡和世界书保存进记录上下文。之后即使角色设定发生变化，旧记录仍能保留创建时的版本信息。

## 六、最常用流程：创建记录并发送给 AI

下面以“我们的日记”为例，其他房间的流程基本一样。

### 1. 创建内容

打开“我们的日记”，新建一篇日记，填写标题和正文并保存。

### 2. 点击“发送给 AI”

点击后，绯界会：

1. 把这条记录同步到统一记录库。
2. 为它绑定当前角色卡和世界书。
3. 生成包含记录 ID、读取钥匙和回复钥匙的任务单。
4. 自动复制任务单。

看到“已复制”或“同步成功”提示后，再进行下一步。

### 3. 把任务单发给 AI

切换到已经接好绯界 MCP 的 AI 聊天，把剪贴板内容粘贴发送。

不要手动删除任务单中的：

```text
记录 ID
读取钥匙
回复钥匙
```

AI 应按以下流程工作：

```text
调用 read_crimson_record
→ 读取准确记录
→ 根据记录和绑定设定完成内容
→ 调用 write_crimson_reply
→ 写回完全相同的记录 ID
```

### 4. 回绯界收取回复

AI 显示写回成功后，回到绯界。

可以在对应房间点击“收取新手记”“收取回复”，也可以在控制中心点击：

```text
收取全部 AI 回复
```

回复会自动放回原来的记录中。

## 七、每个房间怎么用

### 绯夜酒馆

1. 填写酒保姓名和客人姓名。
2. 选择招牌酒或随机特调。
3. 保存生成的酒签。
4. 点击“发送给 AI”。
5. AI 完成后收取随杯手记。

随杯手记会优先使用绑定角色的姓名和口吻；没有可用角色卡时，使用本杯酒保姓名落款。

### 绯界咖啡馆

1. 选择推荐故事、随机剧场或私人配方。
2. 自定义时填写核心设定、必须出现、不要出现和故事味道。
3. 生成剧场卡。
4. 点击“发送给 AI”。
5. 回来点击“收取新手记”。

### 我们的日记

1. 新建日记。
2. 填写标题和正文。
3. 保存后点击“发送给 AI”。
4. AI 会依据日记内容和绑定设定写回信。
5. 回到日记查看或收取回复。

### 时光之轮

1. 新建或选择事件模块。
2. 填写主题并运行事件。
3. 在运行记录中点击复制或发送给 AI。
4. AI 读取这一次事件并续写。
5. 回到时光之轮收取结果。

### 旅行小兔

1. 在皇家图书馆启用要旅行的角色。
2. 创建一次旅行记录。
3. 填写目的地或旅行信息。
4. 点击“发送给 AI”。
5. AI 会以当前角色的身份写旅行信。

这里的兔兔是模块吉祥物，真正的旅行者是当前启用角色。

## 八、备份与换设备

### 方法一：导出完整 JSON

这是最简单、最推荐的方法。

1. 打开控制中心。
2. 点击“导出全部”。
3. 保存下载的 JSON 文件。
4. 在新设备打开绯界。
5. 打开控制中心，点击“导入全部”。
6. 选择之前的 JSON 文件。

导入完成后页面会刷新。

### 方法二：使用 Cloudflare 云端恢复

使用主人钥匙可以恢复已经同步过的云端档案。

注意：本地新建但尚未同步的内容不会出现在云端恢复中。

### 方法三：Git 仓库存档

Git 存档适合长期备份，不等同于实时云端。

当前流程：

```text
控制中心导出 Git 存档 JSON
→ 手动上传到私有 GitHub、Gitee 或 GitLab 仓库
→ 以后从仓库下载 JSON
→ 回到绯界导入 Git 存档
```

第一次使用建议选择 Gitee 或自己能稳定访问的平台，并把仓库设为私有。

当前版本尚未实现自动提交到远程 Git 仓库。

## 九、常见问题

### AI 说找不到记录

依次检查：

1. 是否在绯界点击了“发送给 AI”。
2. 是否显示同步成功。
3. 是否复制了完整任务单。
4. 任务单中的记录 ID 是否被修改。
5. 控制中心是否执行过“全部同步”。
6. MCP 是否已经连接。

重新回到原记录，再点一次“发送给 AI”通常最省事。

### AI 能读但不能写回

检查：

- 回复钥匙是否完整。
- AI 是否调用了 `write_crimson_reply`。
- 写回时是否使用了与读取时完全相同的记录 ID。
- 单次回复是否超过 12,000 字。

### 重新生成钥匙后突然不能用了

重新生成钥匙后，必须马上点击：

```text
全部同步
```

否则云端仍然使用上一套钥匙。

### 换手机后记录不见了

本地记录保存在原浏览器中，不会自动跟随账号迁移。请使用完整 JSON 备份、Cloudflare 云端恢复或 Git 存档迁移。

### 清理浏览器数据后还能找回吗？

只有以下情况可以恢复：

- 之前导出过 JSON。
- 之前同步过 Cloudflare 云端，并保留主人钥匙。
- 之前保存过 Git 存档。

三种都没有时，本地数据通常无法恢复。

### Git 配置中的访问令牌会被导出吗？

不会。Git 存档会排除：

- 主人钥匙
- 读取钥匙
- 回复钥匙
- Git 访问令牌

### 手机也能用吗？

可以使用网页和各房间功能。MCP 是否能在手机上调用，取决于所使用的 AI 客户端是否支持远程 HTTP MCP。

## 十、安全提醒

- 主人钥匙不要公开。
- 不要把钥匙提交到公开 Git 仓库。
- 备份仓库建议设为私有。
- 不要把钥匙写入角色卡、世界书或故事正文。
- 发送截图前，检查是否露出钥匙。
- 更换设备前，同时保存完整 JSON 和三把钥匙。
- 成人向模块仅限成年人和明确成年的虚构角色使用。
